ACOMPANHAMENTO CONTÍNUO

O painel está aberto. O observador precisa de um processo separado.

No VS Code, abra um segundo terminal na mesma pasta do projeto e mantenha-o aberto:

python bot.py watch

Se aparecer “sessão pertence a outra versão”, encerre o observador antigo, preserve a sessão com python bot.py observation-archive e execute python bot.py watch novamente. Se STOP estiver acionado, revise a causa antes de retomar.

O observador coleta sinais, sem criar ordens. Patrimônio e ordens simuladas não mudam com essa coleta. Para gerar uma medição da carteira, encerre o observador com Ctrl+C, execute python bot.py once e depois reinicie python bot.py watch. A validação continua impedindo ordens reprovadas. Os testes de código terminam ao exibir OK; não deixam o bot ligado.
